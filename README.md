# 📱 [Stock_n_Scan] iOS 테스트 빌드 설치 가이드 (Windows & Mac)

이 가이드는 개발자용 테스트 파일(`.ipa`)을 본인의 아이폰에 무료로 직접 설치하는 방법입니다.  
사용 중인 컴퓨터(Windows 또는 Mac)에 맞는 섹션을 선택해 진행해 주세요.

---

> ⚠️ **시작 전 필독 (자주 묻는 질문)**
> * **"Mac 쓰는데 Xcode로 바로 열면 안 되나요?"**  
>   👉 전달받은 파일은 프로젝트 원본이 아닌 컴파일된 **`.ipa` 실행 파일**입니다. Xcode의 '기기 관리자' 창은 인증서가 이미 서명된 파일만 허용하기 때문에, **Mac에서도 Sideloadly를 이용해 내 계정으로 즉석 서명하여 넣는 것이 가장 간편하고 오류가 없습니다.**
> * **"아이폰 설정에 '개발자 모드' 메뉴가 아예 안 보여요!"**  
>   👉 정상입니다! 애플 보안상 **앱 설치가 100% 완료되기 전까지는 아이폰 설정에 '개발자 모드' 메뉴 자체가 숨겨져 있습니다.** 앱 설치 후 설정을 열어보시면 나타납니다.

---

## 🪟 Windows 사용자 설치 방법

### 1단계: 필수 프로그램 2개 설치
윈도우가 아이폰을 인식하려면 아래 두 프로그램이 모두 필요합니다.
1. **iTunes (애플 공식 웹 버전)** 설치  
   * ⚠️ **주의:** 마이크로소프트 스토어 버전은 작동하지 않습니다. 반드시 아래 애플 공식 직링크에서 받아주세요.  
   * 👉 [iTunes 64-bit 다운로드 (Apple 공식 직링크)](https://www.apple.com/itunes/download/win64)
2. **Sideloadly (Windows 버전)** 설치  
   * 👉 [Sideloadly 공식 사이트](https://sideloadly.io/) ➔ **`Windows 64-bit Download`** 클릭 후 설치

### 2단계: 아이폰 연결 및 설치
1. 아이폰을 PC에 **USB 케이블**로 연결하고 화면 잠금을 풉니다.
2. 아이폰에 **"이 컴퓨터를 신뢰하겠습니까?"** 창이 뜨면 **[신뢰]**를 누르고 암호를 입력합니다.
3. PC에서 **Sideloadly**를 실행합니다.
   * 상단 `Connected Device`에 본인의 아이폰이 인식되었는지 확인합니다.
4. 전달받은 **`.ipa` 파일**을 마우스로 끌어서 Sideloadly 왼쪽 위 **IPA 아이콘 자리로 드래그 앤 드롭**합니다.
5. **`Apple account`**에 본인의 **Apple ID(이메일)**를 입력합니다.
6. 아래의 **`Start`** 버튼을 클릭합니다.
   * Apple ID 비밀번호 및 아이폰 화면에 뜨는 **2단계 인증 코드(6자리)**를 입력합니다.
7. 아래쪽 로그에 **`Done.`** 문구가 뜨면 설치 완료입니다!  
   *(👉 완료 후 아래 **[공통: 아이폰 최초 실행 설정]**으로 이동하세요.)*

## 🍎 Mac (맥북/iMac) 사용자 설치 방법

*(Mac은 드라이버가 내장되어 있어 iTunes를 별도로 설치할 필요가 없습니다.)*

### 1단계: Sideloadly 설치
1. [Sideloadly 공식 사이트](https://sideloadly.io/)로 이동합니다.
2. **`macOS Download`**를 클릭하여 다운로드 후 실행합니다.  
   *(보안 경고로 안 열릴 경우: 시스템 설정 ➔ 개인정보 보호 및 보안 ➔ '확인 없이 열기' 클릭)*

### 2단계: 아이폰 연결 및 설치
1. 아이폰을 Mac에 **케이블**로 연결하고 화면 잠금을 풉니다.
2. 아이폰에 **"이 컴퓨터를 신뢰하겠습니까?"** 창이 뜨면 **[신뢰]**를 탭합니다.
   *(Mac의 Finder 창에도 기기 신뢰 팝업이 뜨면 '신뢰'를 클릭합니다.)*
3. **Sideloadly**를 실행합니다.
   * `Connected Device`에 내 아이폰이 잡혀 있는지 확인합니다.
4. 전달받은 **`.ipa` 파일**을 Sideloadly 왼쪽 위 **IPA 아이콘 자리로 드래그 앤 드롭**합니다.
5. **`Apple account`**에 본인의 **Apple ID(이메일)**를 입력합니다.
6. 아래의 **`Start`** 버튼을 클릭합니다.
   * Apple ID 비밀번호 및 아이폰 화면에 뜨는 **2단계 인증 코드(6자리)**를 입력합니다.
7. 아래쪽 로그에 **`Done.`** 문구가 뜨면 아이폰 홈 화면에 앱이 설치됩니다!  
   *(👉 완료 후 아래 **[공통: 아이폰 최초 실행 설정]**으로 이동하세요.)*

## ⚙️ 공통: 아이폰 최초 실행 설정 (필수!)

앱 설치가 끝났으므로 이제 아이폰에 숨겨져 있던 개발자 메뉴가 활성화되었습니다. 아래 두 설정을 완료해야 게임이 열립니다.

### ① 개발자 모드 켜기 (iOS 16 이상)
1. 아이폰 **`설정` ➔ `개인정보 보호 및 보안`**으로 이동합니다.
2. 화면 **맨 아래**로 스크롤하면 새로 생긴 **`개발자 모드`**를 탭합니다.
3. 스위치를 **[켬(ON)]**으로 바꾸고 **[재시동]**을 누릅니다.
4. 폰이 다시 켜진 후 화면에 뜨는 팝업에서 **[켜기]**를 누르고 화면 암호를 입력합니다.

### ② 인증서 신뢰하기
1. 아이폰 **`설정` ➔ `일반` ➔ `VPN 및 기기 관리`**로 이동합니다.
2. `개발자 앱` 항목 아래에 보이는 **본인의 Apple ID**를 탭합니다.
3. **`"[본인 이메일]을(를) 신뢰함"`** 파란색 버튼을 누르고 **[신뢰]**를 선택합니다.

## ❓ FAQ
* **Q. 내 Apple ID를 프로그램에 입력해도 안전한가요?**  
  * 네, 안전합니다. 애플이 무료 계정에 제공하는 "개인 기기 직접 서명 기능"을 로컬에서 호출하기 위해 사용되며 외부로 계정 정보가 전송되지 않습니다.
* **Q. 7일 뒤에 갑자기 앱이 안 열리고 튕겨요!**  
  * 애플 정책상 무료 계정으로 설치한 앱은 **유효기간이 7일**입니다.  
  * 7일이 지난 후에도 계속 플레이하려면 컴퓨터에 연결해 Sideloadly에서 `Start`를 다시 한 번만 눌러주시면(덮어쓰기) 게임 저장 데이터 그대로 다시 실행됩니다.

# 📱 [Stock_n_Scan] iOS 테스트 빌드 설치 가이드 (iOS 27 최신 버전 대응)

이 가이드는 PC/Mac을 이용해 테스트용 게임(`.ipa`)을 아이폰(iOS 27)에 직접 설치하는 방법입니다.

---

> ⚠️ **iOS 27 사용자 필독 (자주 묻는 질문)**
> 1. **"설정에 Apple ID가 없어요!"**  
>    👉 최신 버전에서는 명칭이 **'Apple 계정'**으로 바뀌었습니다. 평소 앱스토어 로그인할 때 쓰는 본인 이메일/비밀번호를 그대로 사용하시면 됩니다.
> 2. **"설정에 '개발자 모드' 메뉴가 아예 안 보여요!"**  
>    👉 정상입니다! **컴퓨터에서 앱 설치가 100% 완료되기 전까지는 메뉴 자체가 숨겨져 있습니다.** 앱 설치 후 설정을 열어보시면 맨 아래에 나타납니다.
> 3. **"Xcode로 바로 열면 안 되나요?"**  
>    👉 Xcode는 Mac 전용 프로그램이며 원본 프로젝트가 필요합니다. 이미 빌드된 게임 파일(`.ipa`)은 윈도우/맥 모두 **Sideloadly**를 쓰는 것이 가장 쉽고 확실합니다.

---

## 💻 1단계: 컴퓨터 필수 프로그램 준비

### [Windows 사용자]
1. **iTunes (애플 공식 웹 버전)** 설치 (필수)  
   * ⚠️ MS 스토어 버전은 인식 불가! 반드시 아래 공식 링크에서 받아주세요.  
   * 👉 [iTunes 64-bit 다운로드 (Apple 직링크)](https://www.apple.com/itunes/download/win64)
2. **Sideloadly** 설치  
   * 👉 [Sideloadly 공식 사이트](https://sideloadly.io/)에서 **`Windows 64-bit`** 다운로드 후 설치

### [Mac (맥북/iMac) 사용자]
1. [Sideloadly 공식 사이트](https://sideloadly.io/)에서 **`macOS`** 다운로드 후 실행  
   *(Mac은 드라이버가 내장되어 있어 iTunes 설치가 필요 없습니다.)*

---

## 🔌 2단계: 컴퓨터와 아이폰 연결

1. 아이폰을 컴퓨터에 **케이블로 연결**하고 화면 잠금을 해제합니다.
2. 아이폰 화면에 **"이 컴퓨터를 신뢰하겠습니까?"** 창이 뜨면 **[신뢰]**를 누르고 화면 암호를 입력합니다.
3. 컴퓨터에서 **Sideloadly**를 실행합니다.
   * 상단 `Connected Device`에 본인의 아이폰이 뜨는지 확인합니다.

---

## 🚀 3단계: 게임 설치하기

1. 전달받은 **`.ipa` 파일**을 마우스로 끌어서 Sideloadly 왼쪽 위 **IPA 아이콘 자리로 드래그 앤 드롭**합니다.
2. **`Apple account`** 란에 본인의 **Apple 계정(이메일)**을 입력합니다.
3. 아래의 **`Start`** 버튼을 클릭합니다.
   * Apple 계정 비밀번호를 입력합니다.
   * 아이폰 화면에 뜨는 **2단계 인증 번호(6자리)**를 프로그램에 입력합니다.
4. 아래쪽 진행창에 **`Done.`** 문구가 뜨면 컴퓨터 작업이 끝납니다!  
   *(이제 아이폰 홈 화면에 게임 아이콘이 생깁니다.)*

---

## 📱 4단계: 아이폰에서 최초 실행 설정 (iOS 27 필수)

앱 설치가 완료되어 이제 아이폰에 숨겨져 있던 메뉴가 나타납니다. 아래 설정을 완료해야 게임이 열립니다.

### ① 개발자 모드 켜기
1. 아이폰 **`설정` ➔ `개인정보 보호 및 보안`**으로 들어갑니다.
2. **화면 맨 아래**로 스크롤하면 새로 나타난 **`개발자 모드`**를 탭합니다.
3. 스위치를 **[켬(ON)]**으로 바꾸고 **[재시동]**을 눌러 아이폰을 껐다 켭니다.
4. 폰이 다시 켜진 후 화면에 뜨는 팝업에서 **[켜기]**를 누르고 기기 암호를 입력합니다.

### ② 개발자 인증서 신뢰
1. 아이폰 **`설정` ➔ `일반` ➔ `VPN 및 기기 관리`**로 이동합니다.
2. `개발자 앱` 아래에 떠 있는 **본인의 이메일(Apple 계정)**을 탭합니다.
3. 파란색 글씨로 된 **`"[본인 계정]을(를) 신뢰함"`**을 누르고 팝업에서 **[신뢰]**를 선택합니다.

---

🎉 **이제 홈 화면에서 게임 아이콘을 눌러 플레이하시면 됩니다!**

---

### 💡 유효기간(7일) 안내
* 애플 정책상 무료 계정으로 넣은 앱은 **7일 동안 유효**합니다.
* 7일이 지나 앱이 튕기면, 컴퓨터에 연결하고 Sideloadly에서 **`Start` 버튼만 한 번 더 눌러주시면(덮어쓰기)** 게임 데이터 그대로 다시 실행됩니다.
